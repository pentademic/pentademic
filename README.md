## 🚀 Highlighted Projects

> 🔒 *My daily work on critical MedTech SaaS & MQTT infrastructure at Locacoeur is strictly closed-source and confidential. The projects below are selected academic & engineering highlights.*

### 🐟 F.I.S.H. D.R.O.N.E. & Edge AI Architecture
*Autonomous maritime surveillance drone — STM32H7*

- 🧩 Deployed highly optimized **TinyML** computer vision models on a resource-constrained STM32H7 microcontroller
- 🔬 Comparative study: multi-output **MobileNet** vs sequential pipeline (**YOLO** + **CRNN**) for Object Detection & OCR
- ⚡ Quantization & pruning pipeline via **X-Cube-AI** to meet microcontroller memory constraints

`STM32H7` `TinyML` `YOLO` `MobileNet` `CRNN` `X-Cube-AI` `C/C++`

---

### 💊 M2S — Medicine Management System
*Fully automated modular medication dispensing for hospital environments*

- 🏗️ Master/Slave embedded architecture with **STM32F7 / Nucleo-G4** coordinating multiple subsystems
- 🔑 Position-control servos, dual **RFID** tag readers & embedded cameras to secure the pharmaceutical circuit
- 🛡️ Designed to prevent medication fraud and dispensing errors in hospital settings

`STM32F7` `Nucleo-G4` `RFID` `Mechatronics` `C/C++` `MedTech`
